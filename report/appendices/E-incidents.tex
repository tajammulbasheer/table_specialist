\section*{Integrity checks after the WSL crash}
\begin{itemize}
\item All 20,062 execution-cache records and every result file parse, and no temporary files were left.
\item The response cache passes SQLite's \texttt{quick\_check}.
\item The file locks left nothing stale.
\item 36 stopped sandbox containers were removed.
\end{itemize}

\section*{Operating rules adopted after the incidents}
\begin{itemize}
\item Every long job runs in its own detached \texttt{tmux} session with an append-only log (\texttt{tee -a}).
\item One job per GPU.
\item Checkpoints are copied aside before any resume.
\item Run directories are never deleted, moved or overwritten.
\item Smoke tests precede every new GPU job.
\end{itemize}
